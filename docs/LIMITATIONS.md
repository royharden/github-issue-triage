# Current limits

- The implemented journey uses an explicit original local fixture inventory and deterministic rules.
  It joins intake, indexing, screening, real isolated rules execution, provisional review and dry-run.
  This is not trusted Git capture, authenticated human approval or finished-app acceptance.
- Signed raw-byte webhook projection and atomic local intake/capture are implemented. The listening
  webhook server, live GitHub auth/token transport and repository capture remain unfinished. JWT
  tests use an explicit synthetic signer, not real RSA proof or external authorization.
- Bounded archive validation retains bytes in memory, checks paths/types/collisions/expansion and
  never executes source. Fixed-host read ports enforce redirect/deadline/byte contracts; no real
  HTTP implementation is available. Deterministic indexing supports Python/JS/TS/TSX definitions and
  supported literal routes/flags/configuration; dynamic or incomplete coverage stays explicit.
- The rules child uses an isolated interpreter, environment allowlist and disabled socket connections.
  It is not an OS sandbox against arbitrary same-user processes. Timeout/unavailable judgment holds
  without usable proposals. No live model, provider, GitHub App or external webhook is exercised.
- Review records are agent-provisional rehearsals. The CLI supports current per-field decisions and
  repeatable zero-write label/comment previews, without human authentication or remote apply.
  A damaged journal requires explicit repair; the CLI cannot silently repair or trust its prefix.
- An independent synthetic18dev/18heldout corpus has provisional agent labels. Heldout, generator and
  author diagnostics remain sealed from the tuner. No human Gold, heldout/application evaluation,
  model accuracy/latency/cost measurement or provider default promotion is claimed.
- Canonical S2 rulings/evalkit, S3 providers/ledger and S5 citation source are vendored with source
  maps/licenses and scoped controls. Mock/replay captures remain mock/replay; they establish no
  live model quality, rights, current account access or real human authority. This local fixture
  journey does not require a provider SDK call or expand a corpus/data grant.
- Trusted capture, authenticated operator UI/CSRF/Origin, actual write reconciliation/partial recovery,
  required native/security/data-loss/evaluation checks and independent finished-app review remain.
  No hosted database, cloud/Bolt resource or remote publication is established by local checks.
