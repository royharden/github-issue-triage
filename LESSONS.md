# Lessons

- A fixture inventory proves its retained bytes, not a real Git capture. Reject unsupported
  capture authority even when an object ID has a plausible shape.
- Bind proposals and decisions to the complete current issue, source, labels, mappings, policies
  and evidence. A historical exact retry is a receipt for history, not current action authority.
- Resolve required citations through the actual installed adapter and current policies. A
  syntactically valid pointer or matching digest alone cannot establish evidence availability.
- Journal fsync must precede a success receipt. Preserve torn or uncertain bytes and require
  explicit repair; never silently truncate or manufacture approval. Actor strings do not
  authenticate a human.
- Preserve canonical source bytes and licenses. Relocate meaningful conformance controls and
  block original application/provider imports; file hashes alone do not prove runtime portability.
- A broad `rulings/` ignore also hid canonical source. Use narrow source-file exceptions that
  preserve private journal and bytecode/cache ignores; verify the actual staged path set.
- Capture each command's actual exit. A later successful shell command must not turn an earlier
  whitespace or test failure into a passing receipt. Retain failed diagnostics and correct the
  evidence explicitly.
- New tests must use the actual canonical schema: the citation pointer field is `source_type`.
  Preserve and correct failed test assumptions rather than weakening the runtime contract.
- Separate component checks, repeated detached controls, model-quality measurements, human
  approval and actual remote effects. An unfinished CLI status flag cannot demonstrate a working
  user journey. Finish the smallest normal/refusal workflow before expanding shared components.
- Environment allowlists and an isolated interpreter are useful process boundaries; they are
  not an OS sandbox against arbitrary processes running as the same user. Exercise the actual
  subprocess before claiming that a workflow uses it successfully.
- Delivery/head/job creation and captured local input must share a transaction. A later capture
  write can fail after successful intake; regression-test that all four records roll back together.
- Keep lease-clock tests deterministic and separate from actual child-process journey checks.
  A bounded subprocess timeout must leave an explicit hold, never a passing fallback or usable proposal.
- Pin external fixture-file bytes before parsing and before state creation. Recompute internal
  stored bundle hashes on replay; neither a raw-file pin nor a historical receipt grants human authority.
- Namespace local copied-consumer test wrappers when filenames collide. Preserve canonical test
  bytes and their sibling-helper import mode rather than weakening collection or rewriting producers.
- Pass `-B` explicitly to isolated Python subprocesses. `-I` ignores
  `PYTHONDONTWRITEBYTECODE`; an environment projection alone cannot prevent runtime cache writes.
  Verify the actual child flag and keep a cache-writing negative control inside owned scratch only.
- Bind review challenges to the actual session, origin, issue, proposal, field and journal head.
  Preserve currentness/CAS checks after transport authorization. An operator session does not
  establish human provenance; a typed request double does not prove browser protection.
- URL parsers distinguish absent userinfo (`None`) from present empty strings. Reject any username
  or password presence in configured origins with explicit `is None` checks, not truthiness.
- Preserve exact public dependency versions/hashes and an app-owned cache. A wrong cached wheel
  ABI is a setup gap, not permission to use an incompatible wheel or a source-build fallback.
- Test real HTTP header/cookie/body parsing separately from typed authorization-port controls.
  Bind signed server-issued event IDs/timestamps and preview journal/revision metadata so a
  browser retry cannot fabricate history or silently preview a different accepted decision.
- Session signatures alone do not implement logout. Persist admission/revocation and serialize
  validation plus guarded HTTP work through the same cross-instance gate; preserve unknown schema
  versions without reset. Auth state is not canonical ruling truth or real Human identity.
- Give large parameterized byte controls short explicit IDs: pytest exports the full test ID into
  an environment variable, which has a Windows size limit. Assert rendered HTML after decoding
  entities; do not disable escaping to satisfy a raw-JSON test expectation.
- Native browser form POSTs can emit `Origin: null` under `Referrer-Policy: no-referrer`.
  Keep exact-Origin refusal and use `same-origin` response policy for this local form workflow.
  A browser walkthrough caught the failure that manually supplied ASGI Origin headers missed.
- Specify UTF-8 explicitly when reading and writing product text on Windows. Default locale
  decoding can corrupt existing Unicode or fail on a later read; retain the failed diagnostic,
  compare the exact Git bytes and repair encoding without discarding behavior/document changes.
- Put injected trusted dependencies inside the response error guard. A clock exception before
  that guard can become an outer-framework500 without security headers. Exercise the actual
  framework fault response and unchanged durable state with explicit policy expectations.
